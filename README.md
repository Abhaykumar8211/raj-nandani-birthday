# ✨ Happy Birthday Raj Nandani • Interactive Birthday Experience

A premium, cute, elegant, and interactive mobile-first birthday surprise web experience created especially for **Raj Nandani**.

Designed as a cinematic **step-by-step interactive journey** with zero vertical scroll-bleed, strict step locking, and high-performance animations.

---

## 🌟 Journey Overview

1. **Page 1 — Welcome**: Full-screen entrance with glowing typography, royal crown, and a deep illuminated circular avatar frame featuring Raj Nandani's portrait.
2. **Page 2 — Raj's Birthday Café & Restaurant**: A luxury restaurant-style celebration menu card (*Happiness*, *Birthday Cake*, *Beautiful Memories*, *Little Surprises*, *Good Luck & Dreams*) with interactive order placement, silver service bell sound, confetti, and an animated receipt ticket stamped *"PAID WITH LOVE"*.
3. **Page 3 — Balloon Celebration**: Tap-to-release floating balloons and tap-to-pop balloon game with sound FX and confetti.
4. **Page 4 — Birthday Cake**: Multi-tier illustrated cake with candle flame blow-out, smoke wisps, confetti shower, and wish reveal.
5. **Page 5 — Memory Gallery**: Mobile swipeable photo carousel featuring cherished memories.
6. **Page 6 — Birthday Letter**: 3D envelope with a wax seal that unfolds into a heartfelt, friendship-focused message.
7. **Page 7 — Gift Shop**: Boutique interface with 3 interactive gift boxes that pop open on tap.
8. **Final Page — Grand Celebration**: Celestial midnight starry blackout, royal fanfare, glowing **"RAJ NANDANI"** typography, celebration balloons, and mega confetti explosion!

---

## 🚀 Tech Stack

- **React 18**
- **Vite**
- **Vanilla CSS (Modern Design Tokens, Glassmorphism, 60fps animations)**
- **Web Audio API** (Interactive SFX for bell, pops, blow-out, chimes, and automatic ambient music fallback)
- **HTML5 Canvas** (Lightweight mobile-optimized confetti & particle engine)

## 🏃 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run

```bash
# Clone the repository
git clone <your-repo-url>
cd raj-birthday-surprise

# Install dependencies
npm install

# Start the local development server
npm run dev

# Build for production
npm run build
```

## ⚙️ Customization

All personal details, messages, and photos can be customized easily in:
`src/config/birthdayData.js`
